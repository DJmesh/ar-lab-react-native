# Arquitetura Limpa de Modelos 3D (.glb / .gltf)

Os modelos 3D do projeto AR Lab estão organizados modularmente por categoria pedagógica:

```text
assets/models/
├── math/                     # 🔢 Matemática (Pré-Escola)
│   ├── apple_red.glb         # Maçã Vermelha 3D 🍎
│   └── apple_green.glb       # Maçã Verde 3D 🍏
│
├── geography/                # 🌍 Geografia (Gincana Global 3D)
│   └── earth_globe.glb       # Globo Terrestre Interativo com Rotação Y 🌍
│
├── portuguese/               # 🔤 Português (Alfabetização)
│   └── letter_a_bee.glb      # Letra A com Abelha Animada 🐝
│
├── chemistry/                # 🧪 Química
│   └── h2o_molecule.glb      # Molécula de Água 💧
│
└── biology/                  # 🧬 Biologia
    └── dna_helix.glb         # Dupla Hélice de DNA 🧬
```
